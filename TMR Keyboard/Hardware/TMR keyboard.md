# TMR Keyboard
The goal of this project is to desing and create a TMR keyboard through the iterative design of minimal viable products.
The end goal of this project is to create a 75 -85 percent keyboard with the functionality of TMR switches. On top of this the end product must have addressable RGB and a gasket mount assembly.

This project is broken down into three main parts:
* A simple macropad
* A TMR devboard
* TMR Keyboard
Each part of this project is meant to teach me more skills in how to create the end product of a TMR keyboard.

# Phase 1: Simple Macropad:

Learn how to make a simple keyboard

Basics:

3x3 wired gaksetmount macropad

Chip: STM32F072VB

## Learning Objectives:

- How IO devices work
- How Keyboards work
- Signaling Protocols

## Goals in Iteration:

- Working Macropad PCB
- Macropad Encouslure
    - Gasket mount
- Working Macro Software
    - Ability to code Macropad and edit keybinds

# Phase 2: TMR Devboard

Single Key or multikey TMR switch module that can work with a development board.

## Steps to Success
- Sucessfully use create board with TMR sensor.
    - Understand Sensor signal
    - Signal conditioning for TMR sensor

- Update Macro Software
    -  Ability to recognize the different Devices I create
    -  Ability to code Macropad and edit keybinds
    -  TMR Keyboard functionality
        - Analog Input
        -  Rapid trigger
        -  Adjustable Actuation

# Phase 3: TMR macropad

## Steps to Success

- Working TMR Keyboard
- Working TMR functionality
